# AI 前世身份鉴定

通过本地 MediaPipe 实时检测人脸，恰好一张人脸稳定至少 1.5 秒后进入娱乐分析。结果完全随机，与容貌无关。

摄像头需 HTTPS 和浏览器权限。视频和照片不上传、不保存。所有运行依赖和模型均包含在仓库根目录。

请使用支持 getUserMedia、WebAssembly 和 WebGL 的现代浏览器。

## 抽签规则

每个浏览器本地记录中的首次成功鉴定，蒋介石概率为 89%，其余 15 人均分剩余 11%。后续从尚未抽中的人物中随机抽取，16 人全部抽过后重置一轮，并避免与上一轮末次人物连续重复。刷新页面会保留记录；清除网站数据、无痕窗口或更换浏览器会重新开始。禁用本地存储时仅当前页面内防重复。保存的只有人物抽签记录，不含人脸信息。

## 滑动拼图

分析进度在 55% 暂停，拖动滑块把拼图块与图片缺口重合后松开；失败可重试或换图。背景、缺口和拼图在本地 Canvas 生成，无外部验证码依赖。可使用方向键操作滑块并点击确认。此互动不能替代后端风控验证码，不提供专业反机器人保障。

## 首次资源加载

核心 JS、适用的 SIMD / 非 SIMD WASM 和 TFLite 模型从本站相对路径读取；无 Google / jsDelivr / unpkg 外部运行依赖。以实际读取字节与打包文件长度计算下载百分比；下载后逐文件 SHA-256 校验，初始化单独提示，不将下载完成冒充人脸检测成功。约需读取 10 MB，支持 CacheStorage 缓存，缓存被禁用时仍可直接下载。

本地部署资源不等于托管域名在中国大陆必达：GitHub Pages 的大陆网络访问未实测，无法保证。要建立稳定大陆入口，应使用在当地可访问的 HTTPS 静态托管与域名；腾讯云默认大陆预览链接也有时效限制。

## 结果彩蛋与人物介绍

人物揭晓后随机显示四句娱乐文案之一，5 秒后在当前标签页打开该人物对应的哔哩哔哩讲解或纪录片页面。可点击“留在此页”取消；保存结果、重新鉴定、返回首页或切换后台也会取消倒计时。外部视频可能下架或需要登录，不会将用户的人脸、照片、匹配度或档案编号放入外链。

彩蛋以屏幕底部滑出的圆角弹层展示，带背景遮罩。关闭按钮、点击遮罩或 Escape 均取消自动跳转；可从结果页重新打开人物介绍，重新打开不重启倒计时。

## 四向矩形彩蛋卡片
